# 일기 재료로 쓸 수 있는 API 조사 (2026-11-03)

> 원칙: 일기는 하루 끝(정차 중)에 쓰므로 외부 API도 **트립이 끝난 뒤 한 번** 부른다. 주행 중 호출·표시는 하지 않는다.

## 1. 내부 API (Pleos Connect SDK)

공모전 FAQ 기준으로 쓸 수 있는 SDK는 Vehicle · NaviHelper · TextToSpeech · SpeechToText · FusedLocation 다섯 가지예요.
차량별 지원 여부는 [API 호환성 및 가용성](https://document.pleos.ai/docs/pleos-only/vehicle-app-planning-guide/api-compatibility-availability)에 정리돼 있어요.
- Vehicle: 모델별로 다르고 `checkXXXCapabilities`로 확인
- NaviHelper: 내비 탑재 차량이면 전체 호환
- TTS·STT: 전체 호환
- FusedLocation: 모델별로 다르고 `isSupported`로 확인

| SDK | 일기에 새로 쓸 수 있는 것 | 예시 문장 |
| --- | --- | --- |
| **NaviHelper** (v3.0.5) | 목적지 이름·주소·POI(`DestinationInfo`), 최근 목적지·즐겨찾기(집·회사), 경유지 도착(`onWayPointArrived`), 교통 상황(`RouteStateInfo.trafficStatus`), 남은 거리·ETA, 통행료(`tollFare`), 과속 카메라·주의 구간 알림 | "길이 좀 막혔지만 끝까지 잘 왔어", "휴게소에 들렀다 갔어" |
| **FusedLocation** (v1.1.3) | 위도·경도·고도·진행 방향(`LocationData`), 영역 진입/이탈 알림(`addProximityAlert`) | "높은 산길을 넘었어(고도)", 자주 가는 곳 자동 인식 |
| **Vehicle** (v2.3.2) | 이미 쓰는 것 외에: 트립 연비·전비(`Fuel`/`EvBattery` 효율), 충전 상태, 타이어 공기압, 스마트 글라스·블라인드, 크루즈, 핸들 각도·열선, 앰비언트 라이트 색 | "오늘은 아껴서 잘 달렸어", "햇빛 가리개를 내렸어" |
| **TextToSpeech** (v3.3.1) | 하루 끝에 차가 일기를 읽어줌. 앱 등록 필요 | — |
| **SpeechToText** (v3.3.1) | 아이가 말로 남기는 "오늘의 한마디". 앱 등록 필요 | — |
| **LLM** (문서만 있음) | `generateContent`/`startChat`, 모드 ON_DEVICE·SERVER | 규칙 기반 문장을 자연스럽게 다듬기 |
| **Gleo Interface** | 앱 기능을 Gleo 음성 비서에 연결(function calling). 예: "오늘 일기 읽어줘" | — |

- Vehicle SDK에는 **바깥 기온·날씨 API가 없어요**. 그래서 날씨는 외부 API가 필요해요(실내 온도·와이퍼·성에 제거로 추정만 가능).
- **LLM SDK**는 API 문서만 있고 가이드가 없으며, 공모전 FAQ의 SDK 목록에도 없어요. 쓰려면 운영 측 확인이 필요해요.
- 차속(PERF_VEHICLE_SPEED)은 Vehicle SDK에 없어요. AAOS Vehicle Property이고 승인이 필요해요.

## 2. 외부 API

| 분류 | API | 일기에 쓰는 법 | 메모 |
| --- | --- | --- | --- |
| 날씨 | **기상청 단기예보·초단기실황** (공공데이터포털 / [기상청 API허브](https://apihub.kma.go.kr)) | 트립 시각·장소의 기온·강수·하늘 상태 → "맑은 날 18도", "첫눈" | 무료. 5km 격자(nx, ny)라 좌표를 기기에서 격자로 바꿔 보내면 정확한 위치가 안 나감 |
| 날씨 | **기상청 기상특보** | "폭염 주의보였던 날" | 공공데이터포털 |
| 날씨 | Open-Meteo / OpenWeatherMap | 시연·해외용 대안 | Open-Meteo는 키 없이 무료라 프로토타입에 편함 |
| 공기 | **에어코리아 대기오염정보** (한국환경공단) | 미세먼지 나쁨 + 공기청정 켬 → "공기가 안 좋아서 창문 닫고 달렸어" | 공공데이터포털, 측정소 기준 |
| 해·달 | **한국천문연구원 출몰시각 정보** | 해 질 녘·해 뜰 녘 주행 → "노을 보면서 달렸어" | 계산식으로 기기 안에서 구해도 됨(네트워크 불필요) |
| 날짜 | **한국천문연구원 특일 정보** | 공휴일·명절·24절기·기념일 → "추석 연휴 첫날", "입동" | 공공데이터포털 |
| 장소 | **카카오 로컬 API** (좌표→주소/행정구역, 카테고리 검색) | 도착지 동네 이름, "놀이공원·바다·캠핑장" 판단 → 스탬프 자동 선택 | 하루 호출 한도 있음 |
| 장소 | 브이월드 역지오코딩 (국토교통부) | 카카오 대안 | 무료 |
| 여행 | **한국관광공사 TourAPI 4.0** | 위치 기반 관광지·축제 → "벚꽃 축제 근처를 지났어" | 공공데이터포털 |
| 고속도로 | **한국도로공사 공공데이터**(휴게소·노선) | 휴게소 정차 감지 → "○○휴게소에서 쉬었어" | data.ex.co.kr |
| 충전·주유 | 환경부 전기차 충전소 정보 / 오피넷 | 충전·주유 후 "밥 먹은 곳" 이름 | NaviHelper `getChargerOperatorInfo`로도 일부 가능 |

## 2-1. 추가 조사 (2026-11-04)

### Vehicle SDK에서 새로 찾은 것
[Vehicle SDK 도메인 목록](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/Vehicle/intro)과 사이트맵의 get API 목록을 기준으로 정리했어요.
- 퍼미션은 조회(CAR_*)만 쓰고 제어(CONTROL_CAR_*)는 쓰지 않아요.
- 차종마다 지원이 다르므로 `checkXXXCapabilities`로 확인해요.

| 도메인 · API | 일기 재료 | 예시 문장 |
| --- | --- | --- |
| Seat `getCurrentSeatOccupancy`, `getSeatBeltBuckledState` (CAR_SEATS) | 좌석별 탑승·안전벨트 → 누가 어느 자리에 탔는지 자동으로 짐작 (자리↔가족을 한 번 정해 두면 탑승 시트를 건너뛸 수 있음) | "뒷자리 두 칸이 꽉 찼어", "다들 벨트를 딸깍 맸어" |
| Seat `seat-backrest-angle-position` | 뒷좌석 등받이가 오래 젖혀져 있음 | "뒷자리 친구는 의자 눕히고 쿨쿨 잤나 봐" 💤 |
| Seat `hvac-seat-temperature` / `ventilation` | 좌석 열선·통풍 | "엉덩이가 따끈했어", "시원한 바람이 나왔어" |
| Light `reading-light-state`, `cabin-light-state` | 밤에 실내등·독서등 켬 | "뒷자리에서 불 켜고 책 봤어" |
| Light `front/rear-fog-light-state` | 안개등 켬 | "안개 낀 길을 지났어" (날씨 API 없이도) |
| Light `high-beam-light-state` | 상향등 → 어두운 시골길 | "깜깜한 길을 밝히며 갔어" |
| Window `window-blind-position`, `smart-glass-state` | 햇빛 가리개 내림 | "햇살이 쨍해서 커튼을 쳤어" ☀️ |
| HVAC `hvac-defroster-state`, `hvac-recirculation-state`, `hvac-air-cleaner-state` | 성에 제거, 내기 순환, 공기청정 | "유리에 김이 서려서 닦았어" |
| DrivingMode `driving-mode-state`(ECO/NORMAL/SPORT), `cruise-control-state` | 주행 모드, 크루즈 | "오늘은 아껴 달리기 모드였어" |
| TurnSignal `turn-signal-state` | 깜빡이 켠 횟수 (칭찬용으로만) | "깜빡이를 23번이나 켰어, 똑똑하지?" |
| Door `door-position` | 어느 문이 열렸는지 | "중간에 오른쪽 뒷문이 열렸어" |
| Odometer `trip-since-refill-*`, `distance-driven` | 주유 후 거리, 누적 거리 | "밥 먹고 312km 달렸어" ⛽ |
| Safety `telltales-info`, Tire `low-tire-pressure` | 경고등, 타이어 공기압 낮음 (걱정 말투로만, 겁주지 않기) | "타이어가 배고프대, 바람 넣어줘" |

### 외부에서 새로 쓸 수 있는 것

| 분류 | API | 일기에 쓰는 법 | 확인한 내용 |
| --- | --- | --- | --- |
| 자연 | **기상청 생활기상지수**(자외선) · **꽃가루농도위험지수** | "햇볕이 센 날이었어", "꽃가루가 많이 날렸어" | 공공데이터포털, 무료. 체감온도 등 일부 지수는 종료 예정이라 쓰기 전에 확인 |
| 자연 | **기상청 계절관측**(벚꽃·개나리·단풍·은행 개화·낙엽, 제비 첫 관측 등) | "이 동네 벚꽃이 핀 지 사흘째래" 🌸 | 공공데이터포털 → API허브. 관측값(예상 시기는 민간으로 넘어감) |
| 바다 | **국립해양조사원 조석예보(고·저조)** | 바닷가 도착 시 "물이 빠져서 갯벌이 넓었어" | 공공데이터포털, 무료, 개발계정 자동 승인 |
| 하늘 | **한국천문연구원 월령 정보 · 천문현상 정보** | "보름달이 뜬 밤이었어" 🌕, "오늘 밤 유성우가 온대" | 공공데이터포털, 무료(개발 일 1만 건). 월령은 기기에서 계산해도 됨 |
| 하늘 | 한국천문연구원 음양력 정보 | "음력으로 시월 보름" | 공공데이터포털 |
| 역사 | **국가유산청 문화재 공간정보** | 근처 문화유산 → "옛날 성벽 옆을 지났어" 🏯 | 공공데이터포털, 무료. 좌표·반경 검색 파라미터는 명세서에서 확인 필요 |
| 이야기 | **위키백과 GeoSearch** (`ko.wikipedia.org/w/api.php?list=geosearch`) | 도착지 근처 문서 → 아이에게 들려줄 한 줄 상식 | 키 없이 무료. 2026-11-04 호출 시 엔드포인트는 응답했지만 "too busy" 오류 → 캐시·재시도 필요 |
| 생물 | **GBIF occurrence API** | 도착지 근처 관찰 기록 → "이 근처엔 왜가리가 산대" 🐦 | 키 없이 무료. 2026-11-04 수원 부근 범위 호출로 1.8만 건 응답 확인. 종 이름 한글화 필요 |

- 위키미디어 "오늘의 역사" 피드는 한국어를 지원하지 않아서 뺐어요(404 확인).
- 공통 원칙은 같아요. 좌표는 기기 안에서 동네·격자 단위로 바꿔 보내고, 트립이 끝난 뒤 한 번만 불러요.

## 3. 쓰기 전에 꼭 확인할 것

1. **위치정보법**: 앱 심사 가이드에 "위치정보를 저장·이용하는 서비스는 국가 법령에 따른 등록·신고 확인을 요청할 수 있다"고 되어 있어요([사용자 개인정보 및 보안](https://document.pleos.ai/docs/pleos-only/distribute/app-review-guide/review-user-privacy-security)).
   - 장소·경로를 저장하면 한국에서는 위치기반서비스사업 신고에 해당할 수 있어요.
   - 대안: 좌표는 기기 안에서만 쓰고, 저장은 "장소 이름표·동네 단위"로만 하기.
2. **외부 서버 허용 여부**: 노션 "확인 필요"에 이미 있는 항목이에요. 외부 API를 쓰면 네트워크가 필요하고, 개인정보 처리방침·제3자 제공 고지가 필요해요.
3. **API 키 보관**: 앱에 키를 넣지 말고, 작은 중계 서버를 두거나 키가 필요 없는 공공 API부터 쓰기.
4. **오프라인 대비**: 네트워크가 없으면 차량 데이터만으로 일기를 쓰고, 날씨 문장은 빼기.

## 4. 추천 (공모전 범위)

- **바로 넣을 것**
  - 기상청 날씨: 무료이고, 격자를 쓰면 개인정보 부담이 적어요.
  - 특일 정보: 무료이고 위치가 필요 없어요.
  - 해 뜨고 지는 시각: 기기 안에서 계산해요.
  - NaviHelper 목적지·경유지·교통 상황
- **있으면 좋은 것**: 카카오 로컬(장소 종류로 스탬프 자동 선택), 에어코리아
- **시연 포인트**: 같은 트립에서 "비 + 첫눈 + 공휴일 + 휴게소"가 한 번에 들어간 일기. 차량 데이터와 외부 데이터를 섞어 "폰으로는 못 쓰는 일기"를 보여주기.
