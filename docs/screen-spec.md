# 2. 화면별 상세 기획 — 「차 일기」

> 우리 가족을 가장 많이 태운 차가, 차의 입장에서 쓰는 일기
> "함께 달린 모든 길을, 차가 기억할게요."

## 기준

- **디자인**: [싶 디자인 시스템](https://claude.ai/artifact/Mhev8UMsdUZ6yEhfXfndUQ) 그대로. 규칙은 `docs/design-guide.md`, 토큰은 `design/tokens.css`(싶 tokens.json과 같은 이름·값)
- **화면 크기**: 차량 화면의 앱 영역 가로 1700×1184px / 세로 분할 840×1184px에 싶 pt를 2배로 그림(850×592pt / 420×592pt). 2·3·4·5·6번은 세로 분할 시안도 있음
- **디자인 시안**: `screens/*.html` (가로·세로 분할 토글), 캡처는 `screens/shots/`
- **주행 상태 판단**: Android Automotive 주행 규제(CarUxRestrictions) 기준. 이 문서의 `🚗 주행 중`은 규제가 걸린 상태, `🅿️ 정차 중`은 기어 P(`Gear.getCurrentGearSelectionState`) 상태
- **원칙**: 알림 대신 칭찬하고 기억하기. 문·벨트 **경고는 하지 않음** (이미 차가 함)
- **SDK**: Vehicle(조회·리스너), NaviHelper, FusedLocation(위치) 사용. 차량 제어는 쓰지 않음(앱 마켓 승인 필요). TTS·STT는 앱 등록 후 사용 가능 → 일기 낭독 등 확장 후보
- **일기 생성**: AI 없이 규칙 기반. 이벤트 로그 → 트립 요약 → 규칙 매칭 → 문장 템플릿

## 1. 온보딩 — 차 이름 짓기 + 가족 등록

| 항목 | 내용 |
| --- | --- |
| 상황 | 앱 첫 실행 (정차 중에만 진입 가능) |
| 주행 상태 | 🅿️ 정차 중만. 주행이 시작되면 입력 중이던 단계를 저장하고 4번 화면으로 전환 |
| 보여줄 정보 | ① 인사 "안녕! 나는 우리 가족 차야. 이름을 지어줄래?" ② 차 이름 입력 + 추천 이름 칩 ③ 가족 등록 (이름, 역할: 엄마·아빠·아이·할머니 등, 아이는 색상 아바타) ④ 뒷좌석 자리 지정 (선택) |
| 사용자 행동 | 이름 입력 또는 추천 칩 탭 → 가족 추가 (최대 6명) → 시작하기 |
| SDK 데이터 | `CarInfo`(차종 표시용, 선택). 입력 데이터는 앱 로컬 저장 |
| 컴포넌트 | InputField, 이름 고르기 알약(카테고리 트랙 탭), 가족 고르기(그리드 셀 + 체크 원), WriteButton(초록 CTA) + 되돌리기 버튼(gray2), 단계 바(StepProgressBar) |
| 다음 화면 | 2 홈 |
| 메모 | 키보드 입력은 정차 중에만 가능. 추천 이름 칩(쏘나, 붕붕이, 하늘이…)으로 입력 부담 최소화 |

## 3. 탑승 — "오늘 누구랑 가?" 원탭 선택

| 항목 | 내용 |
| --- | --- |
| 상황 | 🅿️ 정차 중 **뒷문 열림** 감지 (`Door.registerDoorPosition`, ROW_2 영역) → 문 닫힌 뒤 팝업 |
| 주행 상태 | 🅿️ 정차 중만. 선택 없이 출발하면 팝업을 닫고 "지난번 멤버"로 기록, 도착 팝업에서 수정 가능 |
| 보여줄 정보 | 제목 "오늘 누구랑 가?" / 가족 아바타 토글(기본: 지난번 멤버 선택됨) / 뒷좌석 착좌가 감지되면 해당 자리 아이 자동 선택(`Seat.getCurrentSeatOccupancy`, 지원 차종만) |
| 사용자 행동 | 아바타 탭으로 토글 → [출발!] 1탭. 아무것도 안 하면 10초 뒤 자동 확정 (지난번 멤버) |
| SDK 데이터 | `Door.registerDoorPosition`, `Seat.registerSeatOccupancy`, `Gear.registerGearSelection` |
| 컴포넌트 | 바텀시트(헤드라인 → 가족 그리드 셀 + 체크 원 → 자동 출발 StepProgressBar → WriteButton) |
| 다음 화면 | 4 주행 중 |
| 메모 | 앱이 백그라운드여도 리스너가 동작해야 함 → 포그라운드 서비스 + 알림으로 팝업 진입 (차량 OS 알림 정책 확인 필요) |

## 4. 주행 중 — 조용히 기록 중

| 항목 | 내용 |
| --- | --- |
| 상황 | 기어 D/R 또는 주행 규제 시작 |
| 주행 상태 | 🚗 주행 중 전용 화면. **알림·팝업·토스트 없음**, 텍스트 읽기 없음 |
| 보여줄 정보 (1~2초 안에 파악) | ① 큰 상태 문구 "기억하는 중…" + 차 캐릭터 ② 함께 탄 사람 아바타 ③ 지금까지 거리·시간 (숫자 2개) ④ 오늘 잡힌 명장면 스탬프 아이콘 (비, 밤, 고속도로 등, 최대 4개) |
| 사용자 행동 | 없음 (입력 불필요). 선택: [지금 기억하기 ⭐] 큰 버튼 1개 — 1탭으로 현재 시각을 명장면 북마크 |
| SDK 데이터 | `Odometer.registerTripCurrentDrivingDistance/Time`, `Wiper.registerWiperState`(비), Light(밤), Window(바람), HVAC 시트 열선·통풍(추위·더위), `Seat.registerSeatBeltBuckledState`(칭찬용, 경고 X), NaviHelper(목적지명) |
| 컴포넌트 | 상태 알약(탭 모양), 큰 숫자(`doc-dday`), 스탬프(배지 메달), 되돌리기 버튼 모양의 "지금 기억하기" |
| 다음 화면 | 정차(P) → 5 도착 |
| 명장면 규칙 예 | 와이퍼가 꺼짐→켜짐 = "비 시작" / 30분 이상 연속 주행 = "긴 여행" / 일몰 이후 전조등 = "밤길" / 아이 벨트 출발~도착 내내 체결 = "벨트 칭찬 ⭐" |

| 다음 화면 | 2 홈 (하루 끝이면 6 그림일기 카드 노출) |
| 메모 | FusedLocation 좌표를 함께 저장 → 같은 곳에 다시 도착하면 이름을 자동 제안 (isSupported()가 false면 이름표만 저장) |

## 10. 설정 + 시연 모드

| 항목 | 내용 |
| --- | --- |
| 상황 | 탭 바 [설정] |
| 주행 상태 | 🅿️ 정차 중만 |
| 보여줄 정보 | 차 이름 / 가족 관리 (추가·수정·삭제) / 탑승 팝업 켜기·끄기 / 도착 팝업 켜기·끄기 / **시연 모드** |
| 시연 모드 | 미리 녹화한 이벤트 로그(예: "할머니 댁 87km, 비, 준이 벨트") 선택 → 재생 속도(×10, ×60) → 3→4→5→6 화면이 순서대로 흘러가며 일기가 써지는 장면 시연. PT 에뮬레이터 시연용 |
